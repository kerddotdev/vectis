The first build of Vectis, for testing on your own Apple Silicon Mac. It is not published as a signed release yet.

- Disposable, single-job GitHub Actions runners in macOS 26, Ubuntu 24.04 and Windows 11 ARM64 virtual machines.
- Guided preparation for each guest, with verified downloads for macOS and Ubuntu.
- Automatic runners that start when a repository has queued jobs for your labels.
- Workflow migration that opens a pull request for ARM64-compatible jobs.
- Remote control of your other Macs from the app, the CLI and agents.
- A native Mac app, a CLI with JSON output, an MCP server and an agent skill.
